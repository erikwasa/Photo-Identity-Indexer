# Initial non-goals

The initial system will not:

- Modify OneDrive files or write metadata into originals.
- Train or fine-tune a neural network.
- Identify public figures.
- Use hosted recognition APIs whose embeddings cannot be exported.
- Automatically confirm identity suggestions.
- Process videos.
- Build slideshows or a public cloud photo gallery.
- Support several simultaneous database writers.
- Depend on Microsoft Graph, tenant administrators, app registrations, service principals or managed identities.
- Run the review application permanently in Azure.
