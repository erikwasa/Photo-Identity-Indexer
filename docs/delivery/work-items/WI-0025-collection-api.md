# WI-0025: Add collection-ready queries

## Objective

Expose stable queries and neutral exports for photos containing one or more people, with date, confidence and label-status filters.

## Acceptance criteria

- [ ] Any-person and all-person semantics are explicit.
- [ ] Confirmed-only results are supported.
- [ ] High-confidence suggestions are opt-in.
- [ ] A neutral collection manifest can feed later slideshow or album applications.
