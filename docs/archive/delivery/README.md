# Delivery registry (historical, not maintained)

This folder is the former repository-native delivery registry: WI-XXXX work-item documents,
milestones, roadmap, risks, templates and the YAML status shards that the retired
`PhotoIdentity.Docs` tool validated.

It is kept as a historical record only. Nothing here is updated, and nothing here is the
current status of any work. Work items, their status and completion evidence now live in
GitHub Issues and their pull requests (retired in #870). Any instruction in these files to avoid
GitHub Issues or to work only through `PhotoIdentity.Docs` (for example in
`retired-github-issues-2026-10-22.md`) is superseded: use GitHub Issues.

The files were moved here unchanged from `docs/delivery/`. Relative links inside them that point
outside this folder (for example to `../operations/` or the repository root) were not rewritten
and may not resolve.
