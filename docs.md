# Documentation moved

The original single-file architecture plan has been split into living project documentation.

Start at [`docs/index.md`](docs/index.md).

Current delivery status is tracked in:

- [`BUILD_CONTEXT.md`](BUILD_CONTEXT.md) for the active development session
- [`docs/delivery/status/work-items.yaml`](docs/delivery/status/work-items.yaml) for canonical work-item status
- [`docs/delivery/status/milestones.yaml`](docs/delivery/status/milestones.yaml) for canonical milestone membership and status
- [`docs/delivery/status/current.md`](docs/delivery/status/current.md) for a human-readable snapshot

Architectural decisions are recorded under [`docs/decisions/`](docs/decisions/).
